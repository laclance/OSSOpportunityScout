# Provenance

OSS Opportunity Scout originated as a fork of the public GitHub repository `dev-kp-eloper/BountyScout`.

Development subsequently introduced the current package-based implementation, including strategic discovery, scoring, verification, typed state, delivery, GitHub transport, orchestration, and test infrastructure. The OSS-independence cleanup then removed or restructured the remaining historical compatibility surfaces used during that migration.

The historical `laclance/BountyScout` repository is retained as development provenance. This standalone repository was initialized from a clean snapshot of the independently maintained source tree rather than by copying the historical fork's Git history.

The Apache License 2.0 in this repository applies to this independently maintained standalone boundary. It does not retroactively characterize or relicense the historical upstream or fork commit history.

This document records development provenance and the standalone release boundary. It does not assert licensing terms, license grants, or copyright ownership for historical source outside this boundary.
